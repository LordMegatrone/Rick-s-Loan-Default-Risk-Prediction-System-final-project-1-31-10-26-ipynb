# Rick-s-Loan-Default-Risk-Prediction-System-final-project-1-31-10-26-ipynb
Loan Default Risk Prediction

Id: Unique applicant identifier (dropped before modeling)

Income: Annual income

Age: Applicant age in years

Experience: Total work experience in years

Married/Single: Marital status (single, married)

House_Ownership: Housing status (rented, owned, norent_noown)

Car_Ownership: Vehicle ownership (yes, no)

Profession: Applicant occupation

CITY: City of residence

STATE: State of residence

CURRENT_JOB_YRS: Years in current employment

CURRENT_HOUSE_YRS: Years at current residence

Risk_Flag: Target label (0 = No Default, 1 = Default)
